# Bluetooth Mouse Keepalive 1.1

macOS 菜单栏工具。选择一只蓝牙鼠标，设置 5 / 10 / 15 秒通信间隔，减少部分鼠标闲置后需要点击唤醒的问题。

**这是兼容尝试工具，不是通用驱动，也不能保证所有蓝牙鼠标都不休眠。** Mac 必须保持唤醒、蓝牙保持连接、程序持续运行。它不修改鼠标固件、DPI、回报率或休眠参数。

## 下载与安装

从 GitHub Releases 下载 ZIP，完整解压后运行 `Install.command`。也可以把 `Bluetooth Mouse Keepalive.app` 拖到个人或系统 Applications 文件夹。

1. 点击菜单栏“鼠标 ○”→“选择鼠标”，选中已连接的设备。
2. 在“更多 → 授权…”完成系统权限设置。A6 方法需要“输入监控”，其他 BLE 鼠标的兼容读取需要“蓝牙”权限。
3. 默认 10 秒。5 秒通信更频繁；15 秒接近已观察到的 A6 闲置边界，可能因调度延迟失效。
4. 要登录后自动启动，勾选“登录时启动”。勾选表示配置与系统加载均已检查；横线表示配置存在但未成功启用。
5. “更多 → 开始静置测试…”可计时 25 分钟，之后由你确认先移动鼠标是否能响应。测试结果与间隔按鼠标保存。

应用无 Dock 图标，后台运行。主菜单只有一行灰色状态；权限、状态详情、测试和重连放在“更多”里。“更多 → 菜单栏名称…”可修改菜单栏显示文字，最多 12 个字符，留空恢复为“鼠标”。应用名称保持 Bluetooth Mouse Keepalive。A6 模式下会有一个菜单进程和一个负责通信的小进程，这是同一套程序的正常工作方式，不是同时运行了两个版本。

应用为临时签名，未经过 Apple Developer ID 签名和公证。若系统阻止打开，确认下载来源后，在“系统设置 → 隐私与安全”按系统提示处理。受管理的电脑可能不允许运行。

输入监控列表找不到应用时，点击“＋”，添加安装位置中的 `Bluetooth Mouse Keepalive.app`，开启开关并按系统提示退出重开。更新临时签名应用后，macOS 可能要求重新授权。

## 支持范围

| 设备 | 方法 | 已知限制 |
| --- | --- | --- |
| 精确匹配的 A6 Ultra | 标准 HID 指示灯状态报告，跟随 Mac 当前 Caps Lock 状态 | 只在厂商/产品 ID、名称、传输类型、完整 HID 描述符和报告长度均匹配时使用 |
| 其他 BLE 鼠标 | 只读取电量、型号、固件版本等标准蓝牙服务 | 必须能唯一匹配设备名称，并公开可读服务；读取成功不代表能阻止休眠 |
| 经典蓝牙或缺少兼容接口的鼠标 | 暂不支持 | 不发送猜测的配置或固件指令 |

此前 A6 用户反馈长时间静置后可通过移动响应。新版已经过离线检查和通信小进程故障恢复测试；这不等于完成所有设备、间隔和系统版本的长时间硬件测试。Intel 已编译，尚未实机测试。

其他 BLE 鼠标始终显示“读取正常 · 效果待测试”，避免把通信成功误认为保活成功。静置测试只是计时和用户反馈，不会监听鼠标动作来自动证明效果。若中途操作鼠标，应取消后重新测试；暂停、断线、Mac 睡眠或更改间隔会取消测试。若以前超过 25 分钟才休眠，可继续静置到原来的时长再记录结果。

## 1.1 的变化

- 临时断线、连接超时和读取失败自动重试，间隔逐步增加，最长 30 秒；只有确认缺少接口才显示“不支持”。
- Mac 从睡眠唤醒后重新连接。已经深度休眠的鼠标仍可能需要你先点击唤醒。
- A6 通信在独立小进程内执行。若 4 秒内没有应答，仅结束本程序的通信进程，再重试，避免复用尚未完成的报告缓冲区。
- 同一应用只运行一个菜单实例；同一鼠标有互斥锁。检测到旧版 A6 应用时提示先退出，以避免重复保活。
- 枚举设备通常每 30 秒一次，打开菜单时刷新；状态文件最多每分钟更新一次，状态改变时立即更新。启动项检查在打开菜单时执行。
- 每只鼠标单独保存间隔、最近测试结果和最近一次用户反馈有效的间隔。查看详情可看到测试采用的间隔；更改间隔后应重新测试。

## 升级与卸载

从旧版本升级：先在旧版关闭“登录时启动”并退出，再安装新版、完成授权并重新启用登录启动。旧版 A6 若没有关闭入口，可在系统“登录项”移除旧版条目；若是 LaunchAgent 启动方式，还需停用其原启动项。新版不会自动删除他人的启动配置。

新版发现同一标签的旧启动项时会说明冲突，不会覆盖。仅停止软件可选“暂停”或“退出”；卸载前取消“登录时启动”、退出，再移走应用。默认设置保留在当前用户账户内。

## 隐私与本机文件

没有网络上传、音频采集、鼠标移动模拟、键盘输入记录或输入事件回调。为构造 A6 标准报告，只读取当前 Caps Lock 状态；兼容读取的特征值不写日志。持续通信会增加耗电，续航变化未测量。

- 设置域：`local.bluetoothmouse.keepalive`
- 状态：`~/Library/Application Support/Bluetooth Mouse Keepalive/status.json`
- 登录项：`~/Library/LaunchAgents/local.bluetoothmouse.keepalive.plist`
- 互斥锁：`~/Library/Application Support/Bluetooth Mouse Keepalive/Locks/`

应用、脚本和文档使用固定名称，下载包通过版本号区分。设置域和互斥锁在不同版本间保持稳定。

## 从源码构建

需要 macOS、Python 3、Xcode Command Line Tools。无第三方依赖。

```sh
python3 build.py --output ../Bluetooth-Mouse-Keepalive-build
```

脚本编译 arm64 与 x86_64，合并为 Universal 应用、临时签名、运行离线测试并创建 UTF-8 ZIP。脚本使用本机架构运行 Universal 应用的测试。最低系统版本为 macOS 13。

源码中的 `--self-test` 检查型号匹配、回退间隔和互斥锁和菜单名称；`--worker-self-test` 模拟正常通信、阻塞、意外退出和恢复，不访问鼠标。`--list-mice` 只列出系统 HID 设备元数据，不发送保活报告。

仓库未附加开放源代码许可证；公开源码不自动授予再许可等权利。
